description: Save the current case so you can resume later
---

Write the complete session state to a save file (`$ARGUMENTS` as the name if
given, otherwise the case name).

Persist **verbatim**, with nothing summarized or regenerated:

- The sealed case file: skeleton rolls, ground truth, cast, evidence table
  with all three axes, every witness ledger, all twelve juror ledgers,
  opposing counsel's game plan, the judge's disposition
- Live state: current phase, juror scores and the full movement log, evidence
  item states, objection credibility, opening promises, the ruling log if the
  player is Judge, the Rookie teaching nudge if still unused
- Player role and difficulty

Confirm the save in one line. Do not display the contents.
