---
description: Raise an objection during testimony
---

The player objects on grounds: `$ARGUMENTS`.

Load `skills/verdict/references/objections.md` and rule it:

1. Check the timing window — outside it, the moment is gone, no retroactive save
2. Check the grounds against the nine valid grounds. Wrong grounds are
   overruled even when a right ground existed — do not reinterpret charitably
3. Rule sustained or overruled with one short in-character line
4. If sustained, strike and apply per-juror persuasion decay by `Procedural`
   rating
5. Apply the objection credibility cost

Rule exactly as you would if opposing counsel had raised the same objection
in the same posture.

If the player is Judge, they rule instead — this command is opposing counsel's
objection arriving for their decision.
